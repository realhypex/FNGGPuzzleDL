# FNGGPuzzleDL

Extension for `fortnite.gg/shattered` that adds:

- `Download Puzzle`
- `Download Transparent`

![Preview](assets/preview.png)

## Install

- Chrome, Edge, Brave, Opera: open the extensions page, enable developer mode, then `Load unpacked`.
- Firefox: open `about:debugging#/runtime/this-firefox`, then `Load Temporary Add-on`.

Reload the Fortnite.gg page after installing.
